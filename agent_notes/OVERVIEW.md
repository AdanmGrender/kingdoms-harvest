
## Run quickstart

To get started with the project, follow these steps:
1. Install dependencies: `npm install`
2. Migrate the database: `npm run db:migrate`
3. Seed the database: `npm run db:seed`
4. Start the development server: `npm start`# Project Overview

This project is a Telegram Mini App based on the game of castles, farms, and factions. The app is built using modern web technologies, including React for the client-side and Node.js with Express for the server-side.

## Top-level directories
- `.claude`, `.continue`, `.git`: These are git-related directories.
- `client`: Contains the source code for the client-side of the app.
- `deploy`: Scripts and configurations for deploying the app.
- `docs`: Documentation for the project.
- `node_modules`: Node.js dependencies, managed by npm.
- `screenshots`: Screenshots of the app in action.
- `scripts`: Custom scripts for various tasks, such as development and deployment.
- `server`: Contains the source code for the server-side of the app.
- `shared`: Shared resources used across different parts of the project.
- `tools`: Tools and utilities for development and testing.
